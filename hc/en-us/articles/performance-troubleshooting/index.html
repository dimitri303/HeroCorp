Game running slowly or crashing

If the game is stuttering, crashing, or freezing, work through these in order.

1. Update graphics drivers

Outdated GPU drivers cause more than half the performance issues we see. Update directly from the manufacturer: NVIDIA, AMD, or Intel. Do not rely on Windows Update.

2. Drop graphics settings

  1. Resolution scale (drop to 80% or 75%)
  2. Shadow quality
  3. Volumetric effects
  4. Anti-aliasing
  5. Texture quality

3. Verify game files

Steam: right-click then Properties then Installed Files then Verify integrity. Epic: Library then three dots then Verify.

4. Crash on launch

Verify files, run as administrator, disable controller injection software, update DirectX runtime and Visual C++ Redistributables.

5. Crash mid-game

  • Overheating: check temps with HWMonitor. Over 90 degrees Celsius is concerning.
  • Memory pressure: if you have 8GB RAM, close everything else.
  • Unstable overclocks: try stock speeds.
