Game running slowly or crashing

Updated 02 May 2026

If the game is stuttering, crashing, or freezing, work through these in order.

1. Update graphics drivers

Outdated GPU drivers cause more than half the performance issues we see. Update directly from the manufacturer: NVIDIA, AMD, or Intel. Don't rely on Windows Update.

2. Drop graphics settings (in order of impact)

  1. Resolution scale (drop to 80% or 75%)
  2. Shadow quality
  3. Volumetric effects
  4. Anti-aliasing
  5. Texture quality

3. Verify game files

Steam: right-click → Properties → Installed Files → Verify integrity. Epic: Library → ⋯ → Verify. HeroCorp Launcher: Settings → Verify Files.

4. Check background processes

OBS recording, scheduled backups, Chrome with many tabs, Discord hardware acceleration, antivirus scans.

5. Crashes on launch

Verify files, run as administrator, disable controller injection software, update DirectX runtime and Visual C++ Redistributables.

6. Crashes mid-game

  • Overheating: check temps with HWMonitor. Over 90°C is concerning.
  • Memory pressure: if you have 8GB RAM, close everything else.
  • Unstable overclocks: try stock speeds.

If you've tried everything

Send us a crash log from %APPDATA%\HeroCorp\Logs\ and your DxDiag report. We can usually pinpoint the issue in one reply.
