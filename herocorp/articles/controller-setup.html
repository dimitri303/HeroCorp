Setting up controllers (Xbox, PlayStation, Switch Pro)

Updated 02 May 2026

Our PC titles support Xbox, PlayStation, and Nintendo Switch Pro controllers, wired and wireless.

Xbox controllers

Wired: plug in via USB.

Wireless (Bluetooth): hold the pairing button until the Xbox button blinks rapidly, then pair via Windows Bluetooth settings.

PlayStation 5 (DualSense)

Wired: connect via USB-C.

Wireless: hold PS + Create button together until the light bar flashes, then pair via Bluetooth.

For haptics and adaptive triggers, launch through Steam with PlayStation Configuration Support enabled.

Nintendo Switch Pro

Hold the small pair button at the top until the LEDs scroll, then pair via Bluetooth. If buttons are mapped wrong, enable Switch Pro Configuration Support in Steam.

Controller isn't responding

  • Make sure the game window has focus
  • Check the controller is detected in Windows Game Controllers
  • Restart the game
  • Check Steam Input isn't intercepting unexpectedly

Customising bindings

In Sundered Spire: Options → Controls → Controller. Full remapping is supported, including analogue triggers.
